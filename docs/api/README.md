# API contract

`openapi.reference.json` is the contract this backend has to honour. It is the OpenAPI document
generated by the original Spring Boot backend
([`dolek122/Songly-backend`](https://github.com/dolek122/Songly-backend), `docs/api/openapi.json`
at commit `ebbb87d`, 2026-10-28), copied verbatim.

The mobile app ([`dolek122/Songly-mobile`](https://github.com/dolek122/Songly-mobile)) keeps its
own copy of the same file and generates its models from it. That is why a ported endpoint must
match it exactly: path, method, status codes, field names, enum values and error codes. A
difference here is a bug in the port, not a style choice.

The live document of this backend is served at `/openapi/v1.json` (UI at `/scalar`).
